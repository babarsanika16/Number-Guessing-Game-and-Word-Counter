# Number Guessing Game & Word Counter

## About Project
This is a beginner-level Python project.

It contains two programs:

1. Number Guessing Game
2. Word Counter

## Features
- Random number generation
- Score calculation
- Attempt counter
- Text file reading
- Word frequency counting
- Top 10 common words

## Scoring Rule
The game starts with 100 points.
10 points are deducted for every wrong guess.
The player gets 5 attempts.
